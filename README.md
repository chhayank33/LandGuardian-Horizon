# LandGuardian-Horizon
AI-powered unified land records portal for Bihar's HORIZON challenge. Aggregates Bhulekh data, OCR for Kaithi deeds, blockchain verification, AR geo-overlays, and dispute prediction. Demo project: 1-tap property trust from survey chaos to secure transactions. Built with Python/Flask, Tesseract, Polygon, AR.js. [Hackathon Winner Potential]
